# BullCare UG 🐂 - Offline Cattle Recovery Tracker

Built from real pain: My bull in Pallisa was thin, hip bones out, loud cough, neck stretching. 6 injections but no feed plan. Farmers lose cattle because they forget next deworming date and underfeed.

The Problem
Ugandan farmers treat worms but forget the next dose. Thin bulls graze short grass full of worm eggs and never recover.

Solution
100% offline Android app. No internet needed in village.

Features:
- 📸 Bull profile with photo & body score (1-5)
- 💉 Treatment log: Albendazole, Ivermectin, cough level (Little/Loud/None)
- 🗓️ Auto next deworming date + offline alarm
- 🌾 Feed calculator: weight → daily bran, water, pasture rules
- 📈 Recovery graph: weight & cough over time

Tech Stack
Kotlin, Jetpack Compose, Room Database, WorkManager, CameraX, MVVM, Offline-first

 Why This Matters
First app built by a farmer-coder who lived the problem. From Pallisa kraal to GitHub.

Status
🚧 v1.0 in development - core database done, UI next
